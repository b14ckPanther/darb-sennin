# Two moves that cancel out

A robot on a rail logs each move as a signed number of steps. Find the first pair of moves, in order of the later move, whose steps add up to zero. For that later move, pair it with the earliest move that cancels it.

Print the two indexes `i j` (0-based, `i < j`), or `-1` when no pair exists.

**Input.** The first line holds `n`. The second line holds the `n` moves.

**Output.** Two indexes, or `-1`.
