# Fewest tiles for a row

A tiler has unlimited tiles of each listed length. Find the fewest tiles that fill a row of exactly `L` units, end to end, with no gaps and no overlap. A row of length zero needs zero tiles.

Print the fewest number of tiles, or `-1` when no combination fills the row exactly.

**Input.** The first line holds `k` and `L`. The second line holds the `k` tile lengths.

**Output.** One integer.
