# Sliding window maximum

A sensor reports one temperature reading per second. For every window of `k` consecutive readings, report the highest reading in that window, in window order.

When there are fewer than `k` readings there is no window: print an empty line.

**Input.** The first line holds `n` and `k`. The second line holds the `n` readings (it may be empty).

**Output.** The maxima on one line, separated by spaces.
